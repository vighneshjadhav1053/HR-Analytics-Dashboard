# HR-Analytics-Dashboard
An interactive HR Analytics Dashboard built using Microsoft Excel to analyze employee data, explore workforce trends, and visualize key HR metrics using charts, Pivot Tables, and KPIs.
HR Analytics Dashboard

Project Overview

This project focuses on analyzing Human Resources (HR) data using Microsoft Excel to understand employee trends and key workforce metrics.

Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Data Analysis
- Data Visualization

Project Objectives

- Analyze employee data and workforce trends.
- Summarize important HR metrics.
- Create charts and visualizations for better understanding.
- Present employee insights through an Excel dashboard.

Key Skills

Excel, Data Cleaning, Pivot Tables, Data Visualization, Analytical Thinking.

Project File

Download the Excel file from this repository and open it in Microsoft Excel to explore the analysis and dashboard.
